# SpotUI 0.1.0-beta.2

Release date: 2026-08-05

SpotUI `0.1.0-beta.2` is an experimental tester beta for the HiBy R3 Pro II.
It remains intended for device owners who understand custom-firmware recovery,
manual Spotify authorization, and privacy-safe issue reporting.

## Changes since 0.1.0-beta.1

- Expanded Library discovery beyond the previous eight-entry limit so saved
  playlists are loaded from the complete decorated Spotify rootlist.
- Resolved playlist names before display instead of showing repeated
  `Untitled Playlist` placeholders.
- Replaced the stock player's unreliable fork-based SpotUI launcher callback
  with a lightweight broker started before the stock player.
- Preserved manual stock-player use while allowing the SpotUI tile to launch
  reliably after active or paused stock playback.
- Retained the beta.1 playback, queue, search, theme, sleep, diagnostics, and
  private OAuth behavior.

## Compatibility and limitations

- Tested device target: HiBy R3 Pro II only.
- Firmware base: HiBy Mods v1.5 for the HiBy R3 Pro II.
- Playback engine: SpotUI daemon built against librespot 0.8.0.
- Account: user-supplied Spotify Premium account.
- Integration: manually launched from the repurposed stock Qobuz tile.
- Like and unlike writes remain unavailable without a separate Spotify Web
  API authorization flow.
- Bluetooth output, HiBy MSEB control, automatic updates, and a dedicated
  non-Qobuz launcher integration are not included.

Do not install this build on another HiBy model. Read the bundled privacy,
recovery, licensing, and warranty notices before flashing.
