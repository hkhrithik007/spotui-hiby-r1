# SpotUI 0.1.0-beta.1

Release date: 2026-07-27

SpotUI `0.1.0-beta.1` is a developer beta source milestone for the HiBy R3
Pro II. It is intended for experienced developers and device modders with an
existing recovery path. This is not a one-click application install or a
ready-to-flash firmware release.

## Compatibility

- Tested device: HiBy R3 Pro II
- UI target: `mipsel-unknown-linux-musl`
- Playback engine: SpotUI daemon built against librespot 0.8.0
- Account: user-supplied Spotify Premium account
- Integration: manually launched from the repurposed stock Qobuz tile

Do not install this build on an untested HiBy model.

## Highlights

- On-device browsing and queued playback for Liked Songs and playlists
- Tap-safe Search with recent-query history and automatic result refresh after
  supervised daemon recovery
- Latest-tap-wins selection for normal and rapid track input
- Queue-aware Previous, Next, Up Next, and automatic advancement
- Dedicated Now Playing screen with seeking and playback controls
- Persistent shuffle, repeat, brightness, theme, and screen-sleep settings
- Safe screen sleep/wake while playback continues
- Automatic 3.5 mm and 4.4 mm output routing and jack-removal pause
- Ten appearance themes with performance-aware ambient animation
- Staged startup recovery and live WiFi, Spotify, audio, output, and queue
  diagnostics
- On-device `Version 0.1.0-beta.1` identification in Diagnostics

## Device validation

The release candidate passed device testing for:

- normal and rapid selection from Liked Songs and playlists;
- Search playback and automatic search refresh after a daemon restart;
- automatic advancement and queue completion behavior;
- Previous, Next, pause, resume, seeking, Now Playing, and Up Next;
- switching among Liked Songs, playlists, and Search without stale
  highlighting;
- screen sleep/wake with uninterrupted audio and restored brightness;
- 3.5 mm headphone removal and reconnection;
- UI-only restart with the daemon retained;
- full reboot, cold launch, and persisted settings;
- all menus, themes, Diagnostics, version display, and normal Exit;
- playback audio, metadata synchronization, and highlighting.

## Important limitations

- Only the HiBy R3 Pro II has been validated.
- The public repository does not provide modified HiBy firmware, a `.upt`
  image, proprietary binaries, credentials, or a complete toolchain.
- Installation still requires a privately prepared firmware tree and manual
  device work.
- The stock Qobuz launcher tile is repurposed.
- A cold launch may leave the stock interface visible for tens of seconds while
  codec and mixer initialization finish. This delay protects audio startup.
- SpotUI must be launched manually so normal stock-player use remains
  available.
- Like and unlike library writes are unavailable because they require a
  separate Spotify Web API OAuth flow.
- No automatic updater or uninstaller is included.

## Public release contents

The Git tag for this milestone identifies the reviewed source and
documentation only. Tested device binaries and rollback copies are retained
in a private development archive because public binary distribution and
firmware packaging require additional compatibility, licensing, and recovery
work.
